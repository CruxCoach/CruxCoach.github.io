# Board picker images

These are the same referential board-layout previews bundled with the
CruxCoach Android app. They let an organizer visually match the physical wall
while choosing a competition board; they are not decorative artwork.

The underlying board products, layouts, names, and official source imagery
belong to their respective makers: Kilter Grips LLC, Moon Climbing Ltd,
Tension Climbing, Grasshopper, Decoy, So iLL, and Touchstone Climbing.
CruxCoach is not affiliated with or endorsed by them. The processed previews
are used only to identify compatible hardware in this open-source companion.

Provenance, per-file mappings, and the fuller interoperability rationale are
documented in the Android source at
`androidApp/src/main/assets/board_images/README.md` and the project `LEGAL.md`.
